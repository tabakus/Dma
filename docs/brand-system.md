# Бренд-система v2.0 «Старинная библиотека»

Введена 21.11.2026 по заданию владельца: «старинная библиотека, сочные, насыщенные и глубокие цвета,
фон — виды библиотеки, детали, тени и свет; текст не теряется на фоне фото; блоки направлений — матовые».
Палитра и шрифт заголовков заменяют v1.1 (15.11.2026). **Логотип и розовый Akzent сохранены.**
Значения в коде — `src/styles/tokens.css`; компоненты используют только переменные оттуда.

## Принципы

- Основа — тёмное дерево и тени библиотеки; светлые «страницы» из пергамента — для блоков с длинным текстом.
- Насыщенные цвета — переплёт (бордо) и лампа (изумруд): крупные плоскости и тонировка стекла, не текст.
- Золото тиснения — линии, метки, ссылки на тёмном. Розовый — только логотип, главная кнопка и фирменный круг.
- Текст поверх фото всегда лежит на затемнении (scrim) или на матовом стекле; контраст проверяется для
  самого светлого места фото под текстом.

**Светлая «страница»:** класс `.paper` переопределяет семантические роли (текст — умбра, ссылки — переплёт,
линии — `#D6C19C`) и задаёт фон — фото старой бумаги (`public/assets/textures/paper.webp`, 14 КБ),
осветлённое слоем пергамента 45%. Компоненты внутри
`.paper` автоматически получают светлую схему.

**Матовое стекло** (блоки направлений на главной): тонировка `--tint` 52% + `backdrop-filter: blur(18px)`,
рамка `--glass-border`. Без поддержки `backdrop-filter` тонировка плотнее (86%).

## Типографика

- **Literata** (вариативная антиква, оси `opsz` 7–72 и `wght` 200–900), OFL 1.1 — заголовки, крупные
  высказывания, пункты «Результата», слоган. Насыщенность 520–600, оптический размер — автоматически.
- **Inter** (вариативный), 400 / 500 / 600 — основной текст, навигация, кнопки, подписи полей.
- Метки разделов (`.eyebrow`) — строчными, золотом, с короткой линией слева; без прописных и разрядки.

Шкала размеров (`--text-*`) и ритм — без изменений относительно v1.1; трекинг заголовков ослаблен
(антиква не требует сильного сжатия).
